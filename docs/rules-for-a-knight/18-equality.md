# 守则 18：平等（Equality）

## 核心句
每一个人都和你一样重要，不多，也不少。

## 这一章讲什么
- 国王和乞丐，骑士和农夫，出生时一样，死时也一样。
- 你怎么对待"对你没用的人"，才是你真正的样子。
- 不要仰视任何人，也不要俯视任何人。

## 书中的故事或比喻
- 书里讲骑士在路上遇到衣衫破烂的人，有的骑士绕开，有的骑士下马问他需不需要帮助。
- 祖父说：你永远不知道对面的人经历过什么、以后会成为什么。所以用同一种态度对所有人，最省事，也最对。
- 他还说：对待仆人、小孩、动物的态度，比对待贵族的态度更能说明一个人。

## 爸爸想教的道理
1. 不以地位、财富、长相、国籍判断人。
2. 对强者不低头，对弱者不抬头，用同样的眼睛看所有人。
3. 平等不是"大家都一样"，是"大家都一样值得被尊重"。

## 日常怎么做
- 对服务员、清洁工、送外卖的人，和对老板一样礼貌。
- 和孩子说话时蹲下来。
- 听到别人用出身、国家、职业贬低某类人，不跟着笑。

## 容易误解的地方
- 平等不是没有差别、不分对错。
- 平等是态度上的，不是说能力或责任都一样。

## 思考题
1. 你对谁会不自觉地客气，对谁会不自觉地随便？为什么？
2. 别人怎么对待"对他没用的人"，你会据此判断他吗？

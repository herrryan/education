# 守则 11：耐心（Patience）

## 核心句
没有"一生只有一次"的机会。

## 这一章讲什么
- 急躁来自一个错误的想法："如果我现在不抓住，就永远没有了。"
- 这个想法让人做蠢事：匆忙决定、将就、抢。
- 真正重要的东西——能力、信任、关系——都需要时间。急不来。

## 书中的故事或比喻
- 书里用种树来比喻：你不能因为着急就把树苗往上拔。你只能浇水、等。
- 祖父训练托马斯用剑，前几个月只让他练一个动作。托马斯不耐烦，祖父说：你想快，所以你才慢。

## 爸爸想教的道理
1. 耐心不是被动等待，是 **一边做该做的事，一边不催结果**。
2. 大多数好事要的时间，比你以为的长；大多数坏事过去的时间，也比你以为的短。
3. 对别人有耐心，尤其是对孩子和老人。他们的速度不是你的速度。

## 日常怎么做
- 想要马上回复、马上买、马上决定的时候，等一晚。
- 教别人东西时，允许他慢。
- 给自己定长期目标（三年、十年），而不是只看这个月。

## 容易误解的地方
- 耐心不是拖延。拖延是不做，耐心是做了但不催。
- 耐心也不是"什么机会都不抓"。是不因为怕错过而乱抓。

## 思考题
1. 你最近一次因为"怕错过"而匆忙做的决定是什么？
2. 哪件事你一直在催，其实应该给它时间？

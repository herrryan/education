# 守则 7：宽恕（Forgiveness）

## 核心句
不能轻易原谅别人的人，不会有多少朋友。

## 这一章讲什么
- 每个人都会犯错，包括你。你希望别人怎么对待你的错，就该怎么对待别人的错。
- 不原谅，受伤的主要是自己：你每天背着那件事走路，而对方可能早忘了。
- 原谅不是说"你做的对"，而是说"我不想再背着这个了"。

## 书中的故事或比喻
- 书里用了"两个修士过河"的故事：
  - 两个修士走到河边，一位女子过不了河。年长的修士背她过了河，放下她，继续走。
  - 年轻的修士一路都在生气：我们有戒律不能碰女人，你怎么能背她？
  - 走了很久，年轻修士终于忍不住问了。年长修士说：我在河边就把她放下了，你怎么到现在还背着？
- 道理：不原谅，就是一直"背着"。

## 爸爸想教的道理
1. 原谅是给自己的礼物，不是给对方的。
2. 原谅可以很快，信任可以慢慢来。这是两件事。
3. 也要原谅自己——骑士会犯错，骑士不会一直躺在错里。

## 日常怎么做
- 想到某个人还会生气，就是还没放下。试着每天少背一点。
- 对方道歉时，说"好，过去了"，然后真的让它过去。
- 自己做错了，道歉、补救、然后放下，不要反复自责。

## 容易误解的地方
- 原谅 ≠ 和好。可以原谅一个人，同时不再来往。
- 原谅 ≠ 假装没发生。

## 思考题
1. 你现在还"背着"谁？放下他，你会轻多少？
2. 你最难原谅的，是别人还是自己？

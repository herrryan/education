# 守则 3：感恩（Gratitude）

## 核心句
对于"活着"这份一直在给你的礼物，唯一聪明的回应就是感谢。

## 这一章讲什么
- 你没有做任何事就得到了生命、身体、这个世界、太阳、水、食物。
- 既然这些都是白给的，那么抱怨就是不讲理的，感谢才是讲理的。
- 感恩不是情绪，是一种 **看事情的方式**。

## 书中的故事或比喻
- 书里用了日常的小事来讲：清晨的光、一顿饭、能走路、能看见。这些东西平时根本不会被注意，直到失去。
- 托马斯回忆祖父每天早上起来的习惯：先对这一天说一声感谢，再开始干活。

## 爸爸想教的道理
1. 不满足的人永远不会满足，因为他盯着的是"没有的"。
2. 感恩的人更勇敢，因为他知道自己已经拥有很多，输得起。
3. 感恩让人慷慨（第 13 条），因为知道自己得到的本来就是白给的。

## 日常怎么做
- 睡前写下今天三件值得感谢的事，要具体（不写"家人"，写"今天妈妈给我热了汤"）。
- 遇到坏事时问自己："这件事里有没有一点点值得感谢的？"
- 吃饭前停一秒。

## 容易误解的地方
- 感恩不是假装开心、不是压抑难过。可以同时难过和感谢。
- 感恩也不是"知足就不努力了"。

## 思考题
1. 今天有哪件事，你平时觉得理所当然，其实是礼物？
2. 一个每天抱怨的人和一个每天感谢的人，十年后会有什么不同？

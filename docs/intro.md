# 课程导言：告别做题家思维

那些真正决定资源分配、晋升通道与阶层壁垒的规则，从来没有写在公开的手册与教科书中。

成文规章负责秩序与合规，而未经宣之于口的“隐性知识”，才是权力与利益流转的真实底牌。

普通人常常带着“考试思维”步入社会：认真做题、准时交卷、等待批改、按劳分配。他们相信只要把公开的条文执行到极致，系统就会给予公正的回报。然而在真实的竞技场里，优势圈层运转的是截然不同的两套逻辑——“坐庄思维”与“套利逻辑”。

在这门课程中，我们**不讲抽象的方法论，也不列教条的行动清单**。所有的原理、机制与人性试炼，都浸润在具体的场景、博弈与故事之中。因为一切未被明文写出的规则，只有在具体的冲突与决断里，才会露出它的真正形态。
